# Free Router and IP Tools

RouterNAT provides free browser-based tools for IP addresses, routers, Wi-Fi, NAT, subnets, DHCP, DNS, and network security. Most calculations run locally in your browser and require no registration.

## Explore the tools

- [All router and network tools](https://routernat.com/tools/)
- [Check your public IP address](https://routernat.com/what-is-my-ip/)
- [Look up an IP address](https://routernat.com/ip-lookup/)
- [Check a connection for CGNAT](https://routernat.com/cgnat-check/)
- [Calculate an IPv4 subnet](https://routernat.com/ipv4-subnet-calculator/)
- [Plan static IP and DHCP reservations](https://routernat.com/static-ip-dhcp-reservation-planner/)

## About RouterNAT

[RouterNAT](https://routernat.com/) publishes practical router, NAT, Wi-Fi, and network-security resources for home and small-office users.

These links point to the live tools. This repository contains public documentation only; the RouterNAT CMS and server configuration are not published here.
