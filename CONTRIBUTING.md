# Contributing and reporting problems

This repository tracks public RouterNAT tool documentation and link maintenance. It does not contain the private production application.

## Useful reports

Open an issue when you find a broken resource, reproducible calculation error, unclear field label, accessibility problem, or missing explanation that prevents a tool from being used correctly.

Include the tool URL, sanitized inputs, expected output, actual output, browser version, and the smallest reproducible sequence. Never publish router credentials, API keys, recovery codes, configuration backups, or unredacted personal network information.

Security-sensitive reports should be sent through the private contact method listed at [routernat.com/contact/](https://routernat.com/contact/), not through a public GitHub issue.
